## Test strategy
- **Equivalence:** all 3 golden scenarios (`CBACT04C`, `CBTRN02C`, `CBACT04C-after-CBTRN02C`) must be byte-identical. None of their accounts is over limit, so any diff is a regression.
- **New:** `cr2_overlimit.sh` covers AC2–AC8. For AC7, the script also runs the `baseline` tag's `CBACT04C` (`git show baseline:app/cbl/CBACT04C.cbl` into a temp copy) on the same input and compares the non-fee records with TRAN-ID masked.
- **AC9:** check `trancatg.txt` with `wc -l`, `sort -c` and a per-line length check, inside the test script.

Commands:
```
legacy/harness/golden.sh --check
```

## Risks
- Golden drift from `MOVE SPACES TO TRAN-DESC` or from moving the hook. *Mitigation:* run `golden.sh --check` right after the COBOL edit, before writing the test.
- Expected files just snapshot a bug. *Mitigation:* the script asserts computed values independently, and the expected files are reviewed by hand.
- AC7 baseline build needs the harness to compile an alternate source. *Mitigation:* if `run.sh` can't take a different source path, fall back to asserting the masked records against hand-derived values, and note it in the PR.
- The `9(04)` category move (`'05'` alnum vs `0006` numeric). *Mitigation:* assert the bytes `0006` at offset 18.
- `INPUT_DIR` replaces only the DDs that are given. *Mitigation:* supply all 3 edited DDs, and use stock data for XREFFILE.
