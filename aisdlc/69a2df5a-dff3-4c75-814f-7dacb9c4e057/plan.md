# CR-2 Plan: over-limit fee in `CBACT04C`

Spec: [spec.md](spec.md). Intent: [intent.md](intent.md).

## Files, in order

1. `legacy/tests/cr2-overlimit/input/{TCATBALF,ACCTFILE}.txt` contain the scenario inputs, based on `legacy/golden/CBTRN02C/`
   (non-zero balances). XREF and DISCGRP stay as the sample data. Changes:
   - `00000000001`: balance > limit, plus a sorted extra `010002` TCATBAL record, so it has **2 non-zero-rate records** (rates 15, 25)
   - `00000000002`: balance > limit, with the standard records
   - `00000000003`: balance **= limit** (no fee)
   - `00000000004`: balance > limit, with only its `030001` record (all rates 0, fee per Q1)
   - `00000000050`: balance > limit, the last account (R1: fee tran, no rewrite)
2. **Before any COBOL edit**, run the unmodified program on these inputs and save the output to
   `legacy/tests/cr2-overlimit/baseline/`. AC5 is checked against this run.
3. `app/cbl/CBACT04C.cbl`: spec rules 1-5 (WS field, move the hook, `1400`, `1400-B-WRITE-FEE-TX`, clear `TRAN-DESC`).
4. `app/data/ASCII/trancatg.txt`: insert `010006Over-limit Fee` (60 bytes + CRLF) after `010005`.
5. `legacy/tests/cr2-overlimit/expected/`: outputs from the modified program. Check them against the baseline
   with `diff` (only fee trans, tran-id shifts and the 3 posted over-limit balances differ) before committing them.
6. `legacy/tests/cr2_overlimit_fee.sh` runs the scenario twice with `INPUT_DIR=.../input` and diffs each run against
   `expected/`. It also runs independent awk assertions:
   - one `0006` tran per account in {1,2,4,50}, none for the others
   - fee fields and amount `0000000250{`
   - balances for 1, 2, 4 = input + interest + 25.00, and 50 unchanged
   - the other accounts' ACCTFILE lines equal `baseline/`
   - `trancatg.txt` has 19 lines and contains the `010006` line

   Exit status is non-zero on any failure.

## Test strategy and commands

```
legacy/harness/golden.sh --check          # AC1: 3 golden scenarios unchanged
legacy/tests/cr2_overlimit_fee.sh         # AC2-AC7
```
The golden scenarios prove the no-fee path is unchanged. The new scenario proves the fee path.

## Risks

| Risk | Mitigation |
|---|---|
| `STRING` leaves leftover desc bytes after a fee tran | `MOVE SPACES` before each STRING; the script asserts the interest desc ends in spaces |
| Expected outputs are generated by the code under test (circular) | the baseline diff plus independent awk balance and fee-count checks |
| Moving the hook changes the golden output | it writes nothing when not over limit; `golden.sh --check` gates it |
| The harness KSDS load rejects an unsorted TCATBAL | keep the input sorted by key; check RC 0 and the record counts in SYSOUT |
| The R1 case looks like a bug to reviewers | it is asserted explicitly and commented in the script as preserved |

## Effort

About 20 min to build and about 10 min to test (two harness runs plus golden check, each about 1 min).
