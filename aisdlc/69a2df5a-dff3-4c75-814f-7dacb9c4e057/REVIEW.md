## Findings

1. **nit**: `app/cbl/CBACT04C.cbl:528`, `:541`, `:546`. These lines run to 81-90 columns. Past col 72 there are only trailing spaces, so they compile fine, but they break the file's 80-column layout. Trim them to match the surrounding lines.
2. **nit**: `app/cbl/CBACT04C.cbl:572`. The extra blank line added after `EXIT.` of `1400-B-WRITE-FEE-TX` isn't in the file's style. Delete it.
3. **nit**: `app/cbl/CBACT04C.cbl:528-570`. `1400-B-WRITE-FEE-TX` is almost a copy of `1300-B-WRITE-TX` (about 40 lines). The spec asked for this, and it's fine for a minimal COBOL change. A later refactor could share one write paragraph with cat, desc and amount as parameters.
4. **nit**: `legacy/tests/cr2-overlimit/input/TCATBALF.txt`, the a/c 1 `010002` record. Its amount is `00000001000`, which ends in a plain digit, not the `{` overpunch the other records use. GnuCOBOL reads it as +10.00 (the interest of 0.20 confirms this), but `0000000100{` would match the data convention.
5. **nit**: `legacy/tests/cr2_overlimit_fee.sh:13`. The harness's stderr is thrown away, so a failing run only prints `run N exited non-zero`. Consider printing `$W/runN/SYSOUT.txt` when a run fails.
